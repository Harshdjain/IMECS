💻 Access on Windows & Mac Laptops

The SOS Trigger and Caregiver Dashboard are fully optimized for PCs and Laptops running Windows or macOS (Apple Mac):

  • Windows (Chrome/Edge): Click the "Install App" icon (looks like a monitor with a down arrow) at the right end of the browser address bar to install it as a native desktop application.
  • macOS (Safari): Click the browser File menu and select "Add to Dock" to turn the app into a standalone Mac dock icon.
